# ボードゲームを作ってみよう！

[CoderDojo 青山 #12](https://coderdojoaoyama.connpass.com/event/412221/) のスライドです（[Slidev](https://sli.dev/) 製）。

公開先: https://champierre.github.io/boardgame/

```bash
npm install
npm run dev     # 編集しながらプレビュー
npm run build   # dist/ に静的サイトを出力
```

`main` に push すると GitHub Actions が GitHub Pages にデプロイします。
